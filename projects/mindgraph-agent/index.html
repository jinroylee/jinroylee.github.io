MindGraph: LangGraph counselling agent

A counselling chatbot that chooses its conversation path based on what the user needs — crisis response, CBT-style reframing, guided self-help exercises, or general counselling — and fills the knowledge gaps of a general-purpose LLM with curated documents through RAG.

Agent design

The state graph. Dashed edges are conditional routes chosen from state flags; every path ends in summary_writer so each session is summarised.

Each node owns one job:

  • detect_emotion → crisis_path: on signals of self-harm or suicide, responds immediately with a crisis response.
  • session_initializer: retrieves the user’s summarised conversation history.
  • diagnose: assesses the user’s psychological state.
  • therapy_planner1, therapy_planner2: search documents on self-help therapy techniques.
  • distortion_detector → reframe_prompt: responds to cognitive distortions using CBT-based material.
  • counseling_dialogue: general clinical counselling conversation.
  • guide_exercise → collect_feedback → adjust_instruction: a feedback loop after a self-help exercise.
  • summary_writer: summarises the session.

Branching is driven by state values such as risk_level, needs_therapy, and is_feedback.

Retrieval

  • Store and embeddings. Pinecone, with OpenAI text-embedding-3-small (1,536 dimensions).
  • Collections and chunking. Separate collections for crisis resources, counselling resources, reframing templates, and therapy resources, chunked at 1.5–2k characters with 250–300 characters of overlap.
  • Search. MMR search, plus query rewriting with reciprocal rank fusion: the original query and three summarised or refined rewrites are searched, and their results merged. The aim is higher recall and fewer hallucinations.

Memory

  • Conversation history is stored in PostgreSQL through a PostgresSaver checkpointer.
  • Messages beyond the context window are summarised and accumulated in the vector database.
