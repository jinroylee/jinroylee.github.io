Problem

The goal was an LLM-based pipeline from topic to published post, aimed at SEO and global, multilingual reach: more search traffic, less marketing effort, and smoother operations.

What I built

Blog generation engine

  • Trend-based keywords. Searches Google News and FAQs so posts reflect current topics, and caches keywords so the same one is not reused within a short period.
  • Research and outlines. Uses the Perplexity API and SERP API (Google FAQ and news) to analyse the topics and structure of popular posts. I defined four blog patterns, each with its own research and generation strategy.
  • Writing. ChatGPT struggled to generate long documents in one pass, so generation is split by section. The intent of each section — product comparison, concept explanation, review, and so on — is detected automatically, and matching few-shot examples are loaded from a database. This gives varied, human-like structure while keeping answers consistent.
  • Images. An LLM writes a search query or generation prompt for each section, and suitable images are found or generated and inserted automatically.

Blog infrastructure on Kubernetes

  • Runs WordPress Multisite on Kubernetes, with an NFS volume so data survives pod restarts.
  • A ConfigMap and init-container bootstrap script automate initial blog setup and apply style templates.
  • A new blog site is set up just by registering a DNS record and adding its URL to the Ingress.
  • An operations UI shows marketers each post’s generation progress step by step, and lets them manage and monitor running blogs.

Multi-platform publishing

  • Publishes blog posts to WordPress, Webflow, and Medium, and videos to YouTube and TikTok.
  • OAuth2 login in the UI with credentials stored in a database, so marketers can connect platforms themselves.
  • When an API quota runs out, publishing falls back to Puppeteer-based UI automation, lowering the failure rate and keeping bulk publishing stable.

Results

  • 15 blog sites in operation, with more than 1,500 pieces of content generated and published automatically.
  • Visitors from German- and Japanese-language markets up 5% over two months.
  • An average of 78K impressions and 400+ clicks.
