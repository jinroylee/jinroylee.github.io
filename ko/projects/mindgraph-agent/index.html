MindGraph: LangGraph 기반 상담 에이전트

사용자에게 필요한 것에 따라 위기 대응, CBT 기반 인지 재구성, 자가 심리치료 안내, 일반 상담 등으로 대화 경로를 정하는 상담형 챗봇입니다. 범용 LLM의 지식 공백은 RAG로 선별된 문서로 보완합니다.

에이전트 구조

상태 그래프. 점선은 state 플래그에 따라 선택되는 조건부 경로입니다. 모든 경로가 summary_writer로 끝나서 세션마다 요약이 남습니다.

노드마다 역할이 하나씩 있습니다.

  • detect_emotion → crisis_path: 자해/자살 시그널이 감지되면 즉시 위기 대응 답변으로 대응
  • session_initializer: 사용자의 대화 요약 히스토리 검색
  • diagnose: 심리 상태 진단
  • therapy_planner1, therapy_planner2: 자가 심리치료법 관련 문서 탐색
  • distortion_detector → reframe_prompt: CBT 기반 자료를 참고해 인지왜곡 대응
  • counseling_dialogue: 일반 임상심리 상담 제공
  • guide_exercise → collect_feedback → adjust_instruction: 자가 심리치료법 안내 후 피드백 루프
  • summary_writer: 대화 세션 요약

분기는 risk_level, needs_therapy, is_feedback 등의 state 값으로 제어합니다.

RAG 설계 (검색, 재작성, 랭킹)

  • 저장소와 임베딩: Pinecone, OpenAI text-embedding-3-small (1536차원)
  • 컬렉션과 청킹: 위기 대응 자료, 상담 자료, 인지 재구성 템플릿, 치료 자료를 별도 컬렉션으로 분리, 1.5–2k자 단위로 250–300자씩 겹치게 청킹
  • 검색 전략: MMR 검색과 함께 쿼리 재작성 + RRF 사용. 원래 쿼리와 요약/정제한 쿼리 3개로 검색한 결과를 병합해 recall 증가, 환각 감소가 목표

세션과 메모리

  • PostgresSaver 체크포인터로 대화 히스토리를 PostgreSQL에 저장
  • window_size를 넘어가는 대화는 요약해서 벡터 DB에 누적 저장
