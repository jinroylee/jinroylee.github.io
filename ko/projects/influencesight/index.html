InfluenceSight: 소셜미디어 게시물 engagement 예측 모델

소셜미디어 게시물의 잠재적 광고 효과를 정량화하는 프로젝트입니다. LoRA로 fine-tuning한 CLIP 기반 모델이 이미지, 캡션, 댓글로 engagement 점수를 예측합니다. 데이터 수집, 재학습, 서빙은 AWS, RunPod, Airflow로 자동화해 모델을 최신 상태로 유지합니다.

AI 모델

CLIP 인코더는 전부 고정하고, LoRA 어댑터와 작은 회귀 헤드만 학습합니다.
  • 멀티모달 임베딩: CLIP ViT-L/14 이미지/텍스트 인코더로 이미지와 캡션을 각각 768차원으로 임베딩하고, 상위 댓글 5개의 감성 점수를 더해 1537차원 피처 생성
  • 회귀 헤드: 얕은 MLP 회귀(Huber Loss)로 engagement 점수 예측
  • 효율적인 fine-tuning: CLIP 본체 가중치는 동결하고 LoRA(약 2.6M trainable)만 학습 → 메모리, 시간 절감, 과적합 리스크 관리

라벨 데이터 공식

정답 engagement 점수가 따로 없어서 직접 정의했습니다.

  • 반응률 정규화: like_rate = L/V, comment_rate = C/V, share_rate = S/V로 노출 대비 반응 측정
  • 의도적 가중치: share > comment > like 순으로 가중치 부여
  • 노출에 따른 보상: reach_boost = log10(V+1) / log10(F+1) (F는 팔로워 수)로 대형 계정 편향 억제
Score_raw = (wL·L/V + wC·C/V + wS·S/V) · log10(V+1) / log10(F+1)

학습/서빙 파이프라인

수집(Lambda), 학습(Airflow가 트리거하는 RunPod), 서빙(ECS Fargate의 FastAPI)은 S3를 통해서만 데이터를 주고받습니다.
  • 수집: Lambda로 데이터 수집(업데이트) 함수 구현, 결과 데이터는 S3에 저장
  • 학습: 컨테이너화한 학습 코드를 RunPod Serverless에 배포해 요청 시점에만 기동. PyTorch __getitem__에서 이미지를 S3로부터 lazy loading해 CUDA OOM 방지
  • 오케스트레이션: Airflow DAG로 S3 데이터의 전처리 → 학습 → 평가 → 아티팩트 업로드 수행
  • 서빙: ECS Fargate + FastAPI로 REST API 예측 제공, 모델/피처/로그는 S3에 저장
