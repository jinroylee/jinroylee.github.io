딥브레인 AI

다국어 SEO 블로그 LLM 콘텐츠 파이프라인

마케팅팀의 반복적인 콘텐츠 제작/배포 업무를 자동화하는 LLM 기반 엔드투엔드 파이프라인입니다. 자료 조사, 글 작성, 이미지 삽입, 멀티플랫폼 배포까지 자동화했습니다.

  • 15파이프라인으로 운영한 블로그 사이트
  • 1,500+자동 생성, 배포한 콘텐츠
역할
생성 엔진, Kubernetes 블로그 인프라, 멀티플랫폼 배포
소속
딥브레인 AI
유형
회사 프로젝트
기술 스택
  • Nest.js
  • Kubernetes
  • WordPress Multisite
  • Puppeteer
  • 샘플 블로그: speaknow.ai ↗

문제와 목표

토픽 선정부터 게시까지 이어지는 LLM 기반 파이프라인으로 SEO 최적화와 글로벌 다국어 콘텐츠 확산을 하는 것이 목표였습니다. 기대한 효과는 검색 유입 증가, 마케팅 리소스 절감, 운영 효율화였습니다.

주요 기여

블로그 자동화 엔진

  • 트렌드 기반 키워드 생성: Google News, FAQ를 검색해 최신 이슈 반영, 키워드 캐싱으로 단기간 내 중복 키워드 사용 방지
  • 자료 조사와 아웃라인 생성: Perplexity API, SERP API(Google FAQ, news)로 인기 게시물의 콘텐츠 동향과 구조 분석. 4가지 블로그 생성 패턴을 정의하고 패턴별로 자료 조사와 생성 전략 차별화
  • LLM 기반 글 생성: ChatGPT의 긴 문서 생성 한계를 극복하기 위해 섹션 단위 분할 생성 로직 설계. 섹션별 인텐트(제품 비교, 개념 설명, 리뷰 등) 자동 파악, 사전 정의한 모범 예시(few-shot)를 DB에서 불러와 반영 → 사람이 쓴 것 같은 다채로운 글 구조 + 답변 일관성 유지
  • 이미지 추가: 블로그 섹션별로 적합한 이미지의 검색 쿼리/생성 프롬프트를 LLM으로 만들고, 자동으로 생성/검색해 삽입

Kubernetes 기반 블로그 배포 인프라

  • WordPress Multisite를 Kubernetes에서 운영, NFS 볼륨을 마운트해 파드가 재생성되어도 데이터 유지
  • ConfigMap + InitContainer 기반 부트스트랩 스크립트로 블로그 초기 설정, 스타일 템플릿 적용 자동화
  • DNS 레코드 등록 후 Ingress에 URL만 추가하면 새 블로그 사이트 자동 셋업
  • 블로그 생성 과정을 단계별로 시각화한 운영 UI 개발, 마케터가 진행 상태를 확인하고 운영 중인 블로그를 관리/모니터링

멀티플랫폼 콘텐츠 배포

  • 블로그 콘텐츠는 WordPress, Webflow, Medium으로, 비디오 콘텐츠는 YouTube, TikTok으로 자동 배포
  • UI 기반 OAuth2 로그인과 DB 기반 인증 정보 관리로 마케터가 직접 플랫폼 연동
  • API quota가 부족하면 Puppeteer 기반 UI 자동화로 fallback, 배포 실패율을 낮추고 안정적인 대량 배포 가능

성과

  • 15개 블로그 사이트 운영, 1,500개 이상의 콘텐츠 자동 생성/배포
  • 글로벌 SEO 성과: 2개월간 독일·일본어권 방문자율 5% 증가
  • 평균 78K impressions, 400회 이상 클릭 확보
