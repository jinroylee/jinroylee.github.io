딥브레인 AI

AI Studios 비디오 하이라이트와 비디오 시리즈 기능

콘텐츠 크리에이터를 위한 AI Studios 4.0의 신규 기능 두 가지입니다. Video Highlight는 영상에서 하이라이트를 찾아 편집하고, Video Series는 주기적으로 영상을 생성합니다.

  • 90%+fallback 포함 하이라이트 추출 성공률

문제와 목표

콘텐츠 크리에이터는 영상마다 같은 제작 과정을 반복합니다. 사용자의 키워드, 비디오, 파일 등을 바탕으로 주기적 비디오 생성과 하이라이트 자동 추출을 지원하고, 멀티모달 AI 기반의 효율적인 영상 생성 파이프라인을 제공하는 것이 목표였습니다.

주요 기여

Video Highlight (비디오 하이라이트 자동 추출)

  • STT 기반 하이라이트 구간 판독: Azure Speech SDK로 영상 속 음성을 타임스탬프가 포함된 스크립트로 변환, 이를 자동화 서버로 전달하면 LLM이 하이라이트 구간 분석
  • 후처리와 렌더링 자동화: 판독된 구간에 맞춰 영상 자르기와 캡션 삽입, 렌더링 서버로 보내 최종 비디오 생성
  • Fallback 로직: 스크립트가 없으면 YouTube 댓글 데이터를 LLM 분석에 활용, Google Video Intelligence API로 씬 전환, person detection 등 멀티모달 피처 기반 보완

Video Series (주기적 비디오 자동 생성)

  • 입력 UI: 키워드, 비디오 설정값, 엑셀 시트 등을 입력받아 자동 생성 태스크 등록
  • 스케줄러: Kubernetes CronJob이 10분 간격으로 실행되어 DB에서 처리 대기 태스크를 조회하고 비디오 생성 요청. MongoDB 트랜잭션, 클러스터 관리 담당
  • 에러 핸들링: 태스크 결과를 성공/에러/타임아웃으로 구분, 실패한 태스크는 최대 3회 재시도 후 포기 처리와 에러 알림 전송

성과

  • 스크립트가 없는 상황에서도 fallback 로직으로 하이라이트 추출 성공률 90% 이상 유지
  • Video Series 도입으로 파일/URL 입력부터 최종 비디오 산출까지 주기적 비디오 생성 100% 자동화
